# Indico Pen Spike Implementation Checklist

## 1. Scaffold The Repo

- [ ] From repo root, create the solution:

  ```powershell
  dotnet new sln -n IndicoPenSpike
  ```

- [ ] Create the WinUI app:

  ```powershell
  dotnet new winui -n IndicoPenSpike -o src/IndicoPenSpike
  ```

- [ ] Create the WinUI unit test project:

  ```powershell
  dotnet new winui-unittest -n IndicoPenSpike.Tests -o tests/IndicoPenSpike.Tests
  ```

- [ ] Add both projects to the solution.
- [ ] Build immediately with `dotnet build` before changing code.

## 2. Implement The App Shell

- [ ] Set the window title to `Indico Pen Spike`.
- [ ] Add the menu bar, toolbar, and scrollable document area.
- [ ] Add the empty state text from the spec.
- [ ] Wire `File > Open PDF` and toolbar `Open PDF`.

## 3. Implement PDF Loading And Rendering

- [ ] Add PDF picker support for `.pdf` files.
- [ ] Load PDFs with `Windows.Data.Pdf.PdfDocument.LoadFromFileAsync`.
- [ ] Render pages with `PdfPage.RenderToStreamAsync`.
- [ ] Display pages vertically in a `ScrollViewer`.
- [ ] Preserve page aspect ratio and add light gray document padding.
- [ ] Show the opened filename above page 1.

## 4. Implement Annotation Model

- [ ] Add `AnnotationDocument`, `AnnotationStroke`, and `StrokePoint`.
- [ ] Store strokes grouped by page number.
- [ ] Store page-relative points, black color, fixed thickness, and input type.
- [ ] Keep annotations in memory only.
- [ ] Update stroke count after every annotation change.

## 5. Add Ink Layers

- [ ] Add one native WinUI ink layer per rendered PDF page.
- [ ] Align the ink layer directly over the PDF page image.
- [ ] Configure pen drawing.
- [ ] Allow mouse drawing for testing.
- [ ] Keep touch available for scrolling.
- [ ] On completed strokes, update the annotation model and undo stack.

## 6. Add Tool Modes And Eraser

- [ ] Add `Ink` and `Eraser` modes.
- [ ] Add toolbar controls to switch modes.
- [ ] In ink mode, draw black fixed-thickness strokes.
- [ ] In eraser mode, remove whole strokes when tapped or crossed.
- [ ] Attempt inverted stylus eraser detection.
- [ ] Document any inverted eraser limitation in `ARCHITECTURE.md`.

## 7. Add Undo / Redo

- [ ] Add `UndoRedoService`.
- [ ] Track add-stroke actions.
- [ ] Track erase actions if practical.
- [ ] Disable undo/redo buttons when unavailable.
- [ ] Keep native ink and the annotation model synchronized after undo/redo.

## 8. Add Pointer Diagnostics

- [ ] Listen for pointer events on each annotation layer.
- [ ] Display pointer type: mouse, pen, touch, or unknown.
- [ ] Display current page, mode, and pressure when available.
- [ ] Confirm touch updates diagnostics without creating strokes.

## 9. Add Documentation

- [ ] Add `README.md` with prerequisites, build, run, test, and manual validation steps.
- [ ] Add `AGENTS.md` with coding guidance and scope rules for future agents.
- [ ] Add `ARCHITECTURE.md` with project layout, PDF flow, ink model, undo/redo, diagnostics, and limitations.

## 10. Add Tests

- [ ] Test stroke count changes.
- [ ] Test strokes are grouped by page.
- [ ] Test clearing annotations.
- [ ] Test undo.
- [ ] Test redo.
- [ ] Test redo history clearing after a new action.
- [ ] Test erase behavior if erase actions are modeled.

## 11. Final Validation

- [ ] Run `dotnet build`.
- [ ] Run `dotnet test`.
- [ ] Run the app with:

  ```powershell
  dotnet run --project src/IndicoPenSpike/IndicoPenSpike.csproj
  ```

- [ ] Manually verify PDF open, page rendering, scrolling, pen drawing, mouse drawing, touch scrolling, erasing, undo, redo, stroke count, pointer diagnostics, and inverted eraser behavior if hardware supports it.
